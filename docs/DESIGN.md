# Дизайн: канбан-доска задач

Версия 1 от 22.10.2026. Требования — [TZ.md](TZ.md), номера Ф-N ссылаются на него.

## 1. Принципы

- Доска — главный и единственный экран. Всё остальное (создание, просмотр, правка,
  удаление) — диалоги поверх доски, без перехода на другие страницы.
- Компоненты MUI без кастомных обёрток там, где хватает темы. Свой CSS — только для
  раскладки колонок.
- Светлая и тёмная тема по системной настройке (`prefers-color-scheme`).
- Одно действие — один понятный отклик: Snackbar на успех и на ошибку.

## 2. Тема (MUI `createTheme`)

| Токен                 | Светлая   | Тёмная    | Где используется                    |
| --------------------- | --------- | --------- | ----------------------------------- |
| `background.default`  | `#F4F5F7` | `#121417` | фон страницы                        |
| `background.paper`    | `#FFFFFF` | `#1C1F24` | карточки, диалоги                   |
| `column.background`   | `#EBECF0` | `#22262C` | подложка колонки                    |
| `primary.main`        | `#0052CC` | `#4C9AFF` | кнопки, фокус, активная вкладка     |
| `error.main`          | `#DE350B` | `#FF7452` | удаление, ошибки                    |

Приоритет — чип `size="small"`, цвет по уровню:

| Приоритет | Цвет MUI  | Подпись   |
| --------- | --------- | --------- |
| `HIGH`    | `error`   | Высокий   |
| `MEDIUM`  | `warning` | Средний   |
| `LOW`     | `default` | Низкий    |

Цвет колонки — тонкая полоса 3px над заголовком: «Новая» — `info`, «В работе» —
`warning`, «Готово» — `success`.

Типографика — шрифт по умолчанию MUI (Roboto), `body2` в карточках, `h6` в заголовке
колонки. Скругление `shape.borderRadius = 8`.

```text
│ Новая            3   В работе        1   Готово               2     │
│ ┌────────────────┐   ┌────────────────┐   ┌────────────────┐         │
│ │ Название    ⋮  │   │ Название    ⋮  │   │ Название    ⋮  │         │
│ │ Описание в две │   │ (Высокий)      │   │ (Низкий)       │         │
```

- Три колонки — CSS grid `repeat(3, minmax(0, 1fr))`, зазор 16px, отступ страницы 24px,
  максимальная ширина контента 1440px.
- Колонка растягивается на высоту экрана; список карточек прокручивается внутри колонки,
  заголовок колонки остаётся на месте.

```text
├────────────────────────────┤
│ ┌────────────────────────┐ │
│ │ Название            ⋮  │ │
│ │ Описание…   (Средний)  │ │
│ └────────────────────────┘ │

└────────────────────────────┘
```

- Видна одна колонка; вкладки переключают колонку, счётчик — в подписи вкладки.
- Высота экрана — `100dvh`; FAB и низ списка учитывают `env(safe-area-inset-bottom)`.
- Боковой отступ 16px, горизонтальной прокрутки страницы нет.
- Выбранная вкладка не теряется при обновлении данных.

## 5. Карточка задачи

- `Card` с `variant="outlined"`, отступ 12px, зазор между карточками 8px.
- Название — `subtitle2`, до 2 строк с многоточием (`-webkit-line-clamp`).
- Описание — `body2`, `text.secondary`, до 2 строк; если описания нет, строки нет.
- Чип приоритета внизу слева. Кнопка-меню `⋮` справа от названия, `aria-label="Действия"`.
- Наведение — тень `elevation 2`; перетаскиваемая карточка — `elevation 8`, лёгкий
  поворот 2° и непрозрачность 0.9; на исходном месте остаётся пунктирная заглушка.
- Клик по карточке открывает просмотр; клик по меню не открывает просмотр.

## 6. Диалоги

### 6.1. Создание (Ф-2)

- Заголовок «Новая задача». Поля:
  - «Название» — `TextField`, обязательное, автофокус, счётчик `N/200`;
  - «Описание» — `TextField multiline`, 4–10 строк, счётчик `N/5000`;
  - «Приоритет» — `Select`, по умолчанию «Средний».
- Кнопки «Отмена» и «Создать». «Создать» неактивна, пока название пустое, и на время
  запроса показывает `CircularProgress`.
- Ошибки полей — `helperText` под полем после первого ухода с поля или попытки отправки.
- Enter в поле названия отправляет форму; Esc закрывает диалог.
- Если в форме есть ввод и пользователь закрывает диалог — спросить «Отменить изменения?».

### 6.2. Просмотр и редактирование (Ф-3, Ф-4)

- Режим просмотра: название (`h6`), чип приоритета и статус, описание с сохранением
  переносов строк (`white-space: pre-wrap`), даты «Создана» / «Изменена» в формате
  `22 окт. 2026, 14:05`.
- Кнопки: «Переместить в…», «Удалить» (цвет `error`, слева), «Редактировать», «Закрыть».
- Режим правки — та же `TaskForm`, кнопки «Отмена» (возврат к просмотру без запроса) и
  «Сохранить».
- Задача удалена в другой вкладке (`task_not_found`) — диалог закрывается, Snackbar
  «Задача уже удалена», доска перезагружается.

### 6.3. Подтверждение удаления (Ф-5)

- «Удалить задачу «{название}»? Это действие нельзя отменить.» Кнопки «Отмена» и
  «Удалить» (`error`). Фокус по умолчанию — на «Отмена».

На телефоне все диалоги — `fullScreen`.

## 7. Перемещение (Ф-6)

- `@dnd-kit/core` + `@dnd-kit/sortable`: сортируемый список в каждой колонке, колонки —
  зоны сброса (в пустую колонку тоже можно бросить).
- Сенсоры: мышь (начало после сдвига на 5px, чтобы клик оставался кликом) и клавиатура
  (пробел — взять, стрелки — двигать, пробел — отпустить, Esc — отменить).
- На телефоне перетаскивание выключено — используется меню «Переместить в…», задача уходит
  в конец выбранной колонки, вкладка не переключается, Snackbar «Перемещено в «В работе»».
- Оптимистичное обновление: карточка встаёт на новое место сразу; при ошибке сервера
  возвращается назад и показывается Snackbar.

## 8. Состояния (Ф-8)

| Состояние       | Вид                                                                                      |
| --------------- | ---------------------------------------------------------------------------------------- |
| Загрузка        | колонки с заголовками, в каждой 3 `Skeleton` высотой карточки                            |
| Ошибка загрузки | по центру `Alert severity="error"`: «Сервер недоступен. Проверьте, что бэкенд запущен» или «Ошибка на сервере. Подробности в логах»; кнопка «Повторить» |
| Пустая доска    | колонки скрыты; по центру иконка, «Задач пока нет», кнопка «Создать первую задачу»       |
| Пустая колонка  | внутри колонки серый текст «Нет задач» в пунктирной рамке (она же зона сброса)           |
| Snackbar        | снизу по центру, 4 секунды; успех — `success`, ошибка — `error`                          |

Повторная загрузка после первой не показывает скелетоны — данные остаются на экране.

## 9. Доступность

- Все действия доступны с клавиатуры; порядок фокуса — слева направо, сверху вниз.
- У кнопок-иконок есть `aria-label`; колонка — `section` с `aria-labelledby` заголовка.
- Контраст текста не ниже 4.5:1 в обеих темах.
- Диалоги MUI возвращают фокус на элемент, который их открыл.
